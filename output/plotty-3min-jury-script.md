# Plotty: сценарий выступления на 3 минуты

## Распределение

- Илья: 0:00-0:58, слайды 1-6. Проблема, решение, опыт читателя.
- Лиза: 0:58-1:58, слайды 7, 9-10. Мастерская автора, core backend, кредиты.
- Андрей: 1:58-3:00, слайды 8-12. AI beta-reader, ML-архитектура, экономика, финал.

## Текст

**Илья**

Здравствуйте, мы команда FiveCode, и наш проект называется Plotty. Это платформа для фанфиков, где автор пишет, проверяет и публикует историю в одном месте, а AI beta-reader помогает улучшить текст до первой реакции аудитории.

Почему это актуально: фанфикшн уже давно не ниша. На AO3 опубликованы миллионы работ, у Wattpad огромная читательская аудитория, и часть фанфиков потом вырастает в самостоятельные книги. Но у автора есть проблема: до публикации сложно получить быстрый и содержательный фидбек по тексту, логике и канону.

Поэтому мы объединили три вещи: читательскую платформу, мастерскую автора и AI beta-reader. Для читателя это каталог с тегами и фандомами, страницы историй, читалка, лайки, комментарии и личная полка с подборками. В отличие от обычных фанфик-платформ, Plotty сразу связан с авторским процессом и AI-проверками.

**Лиза**

Со стороны автора Plotty работает как мастерская. Можно создать историю, выбрать фандом, рейтинг, жанры и предупреждения, добавить первую главу, редактировать черновик, публиковать его и видеть, чем черновик отличается от опубликованной версии. Это важно: автор не теряет контроль над текстом и может постепенно вести историю по главам.

Backend у нас написан на Go и разделен на core API и AI-сервис. Core API отвечает за регистрацию, сессии, профили, истории, главы, лайки, комментарии, полку читателя, коллекции и кредиты. Данные хранятся в PostgreSQL, Redis используется для быстрых состояний, MinIO хранит изображения, а RabbitMQ связывает основной backend с ML-задачами.

На фронтенде это не статичная витрина: Next.js-приложение ходит в реальные API-контракты, использует React Query для состояния и показывает асинхронные AI-задачи через статусы job. Кредитная модель уже заведена в продукт: стартовый баланс 50 кредитов, платные действия списываются прозрачно.

**Андрей**

Главная техническая часть — AI beta-reader. Мы специально не делаем "замену автора"; AI помогает найти проблемы, а решение остается за человеком.

Проверка орфографии идет через LanguageTool, но с учетом имен персонажей и лора, чтобы система не ругалась на фандомные названия. Проверка логики сравнивает новую главу с лором предыдущих опубликованных глав. Проверка канона использует pgvector: мы ищем релевантные факты по фандому, передаем их в GigaChat и получаем замечания по противоречиям. Еще есть генерация иллюстраций к главе: prompt улучшается по тексту, картинка сохраняется в MinIO и возвращается в интерфейс.

AI-задачи выполняются асинхронно через RabbitMQ: пользователь запускает проверку, frontend получает job id и опрашивает статус, а при ошибке платные кредиты возвращаются. В экономике мы считаем базовый сценарий: около 23 тысяч рублей расходов в месяц и потенциально 77 тысяч выручки на кредитах и PRO-подписке, точка безубыточности — около 150 платящих пользователей.

Итог: Plotty закрывает путь от черновика до публикации. У автора есть текст, логика, канон и иллюстрации в одном рабочем пространстве, а у читателя — сообщество, каталог и удобное чтение.

## Подсказка по демонстрации

На слайдах 6-8 лучше не проигрывать длинный скринкаст целиком. Достаточно показать ключевой экран и проговорить: каталог для читателя, мастерская для автора, AI-панель для проверок.
