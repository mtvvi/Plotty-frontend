# Plotty

Репозиторий команды FiveCode. Проект: Plotty.

Plotty - сервис для чтения, публикации и ведения авторских историй. В проекте есть каталог историй, читательский профиль, библиотека, инструменты автора и AI-функции для работы с главами и визуалами.
